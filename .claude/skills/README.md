# Project skills

Claude Code loads these for anyone working in this repo, including the worker's cloud runs.

- `mellow-design/`: MellowDLP's own design standard (the owner's taste, what was rejected, the ornament and motion system, the process). Written for this project.
- `frontend-design/`: Anthropic's frontend-design skill, unchanged, Apache License 2.0 (`frontend-design/LICENSE.txt`).
- `impeccable/`: the text of the impeccable skill 4.8.1 (`SKILL.md` and `reference/`), Apache License 2.0 (`impeccable/LICENSE.txt`). Its `scripts/` (a launcher that downloads a binary) are left out on purpose; use the `reference/*.md` guides directly.
